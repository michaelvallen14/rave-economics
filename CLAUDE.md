# CLAUDE.md

Full project guidance lives in [IMPORTANT_NOTES.md](IMPORTANT_NOTES.md) —
read it before doing anything in this repo. It covers data handling rules
(HILDA confidentiality deed, Criminal Code penalties for mishandling),
pre-commit enforcement, project structure, and working conventions.

This file stays in place (rather than being renamed itself) because Claude
Code auto-loads `CLAUDE.md` into context at the start of every session —
that auto-load is what makes the rules in IMPORTANT_NOTES.md non-optional
in practice, not just in principle.
